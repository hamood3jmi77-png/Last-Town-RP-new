# LAST TOWN — موقع جديد + لوحة تحكم

موقع **LAST TOWN** معاد بناؤه بالكامل بـ HTML/CSS عادي (بدل React SPA)، مربوط بقاعدة بيانات SQLite، مع لوحة تحكم (Admin Panel) حقيقية تتحكم بكل نص وصورة في الموقع.

---

## التشغيل المحلي (Development)

1. **تثبيت الاعتماديات وإعداد البيئة:**
   ```bash
   cd lasttown_admin
   python3 -m venv venv
   source venv/bin/activate  # في Linux/macOS
   # venv\Scripts\activate   # في Windows

   pip install -r requirements.txt
python3 app.py
```

الموقع يفتح على: `http://localhost:5050`
لوحة التحكم: `http://localhost:5050/admin`

أول مرة تشغل المشروع، بيتم إنشاء ملف قاعدة بيانات `mtrp.db` تلقائياً مع بيانات افتراضية (نفس نصوص الموقع الأصلي).

## بيانات الدخول الافتراضية للوحة التحكم

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `ChangeMe123!`

⚠️ **مهم جداً:** غيّر كلمة المرور فوراً من `لوحة التحكم → إعدادات الحساب` بعد أول تسجيل دخول.

## هيكل المشروع

```
lasttown_admin/

├── lasttown.db         # قاعدة البيانات (تتكون تلقائياً، غير موجودة بالبداية)
├── requirements.txt
├── templates/
│   ├── base.html        # القالب الأساسي (navbar + footer)
│   ├── home.html, faq.html, team.html, careers.html,
│   │   roster.html, leaderboard.html, live.html, onboarding.html
│   └── admin/          # كل صفحات لوحة التحكم
└── static/
    ├── css/style.css     # ستايل الموقع العام (نفس هوية LAST TOWN)
    ├── css/admin.css      # ستايل لوحة التحكم
    ├── images/            # صور الموقع الأصلية
    └── uploads/           # الصور اللي ترفعها من لوحة التحكم
```

## وش تقدر تتحكم فيه من لوحة التحكم

**نصوص كل صفحة على حدة** (Site Identity, Navbar, Home, FAQ, Team, Careers,
تسجيل الدخول, Leaderboard, Live, Roster, Footer) — كل نص في الموقع قابل للتعديل،
بما فيها اسم الموقع، العناوين، الأوصاف، نصوص الأزرار، بيانات التذييل (CR، VAT، الإيميل).

**قوائم قابلة للتكرار (CRUD كامل: إضافة / تعديل / حذف)**:
- الجدول الزمني (THE JOURNEY)
- السيرفرات (Choose Your Adventure)
- الأحداث (MT Events)
- أعضاء الفريق
- صناع المحتوى (Roster)
- الوظائف الشاغرة (Careers)
- الأسئلة الشائعة (FAQ)
- البثوث المباشرة (Live)
- لوحة المتصدرين (يدوي)
- روابط التواصل الاجتماعي

كل قسم فيه صور، تقدر ترفعها مباشرة من جهازك من داخل نموذج الإضافة/التعديل.

## ملاحظات مهمة

- هذا مشروع **جديد بالكامل** — تم بناؤه من الصفر، بدون أي أدمن أو ربط قديم
  من الموقع الأصلي. النصوص الافتراضية مأخوذة من محتوى الموقع الأصلي فقط
  للحفاظ على استمرارية المحتوى، لكن الكود والقاعدة والأدمن كلها جديدة.
- خادم التطوير المدمج في Flask (`python3 app.py`) مخصص للتجربة المحلية فقط.
  للنشر الفعلي على الإنترنت، شغّل المشروع خلف خادم إنتاج مثل `gunicorn`
  أو `waitress`، خلف Nginx أو أي reverse proxy، وفعّل HTTPS.
- غيّر `app.secret_key` في `app.py` (أو عيّن متغير البيئة `MTRP_SECRET_KEY`)
  لقيمة عشوائية سرية قبل أي نشر فعلي.
- زر "Sign In" العام (تسجيل دخول اللاعبين عبر Discord/Steam/الإيميل) هو نموذج
  واجهة فقط حالياً (مطابق للأصل) — ما يوجد نظام مصادقة فعلي خلفه؛ لو تبي
  تفعيله فعلياً (OAuth مع Discord/Steam) نحتاج شغل إضافي منفصل عن لوحة التحكم.
